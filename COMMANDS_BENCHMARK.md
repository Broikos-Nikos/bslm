# Command benchmark

144 commands written by hand from the chat audit, in the author's own style,
never seen by the training templates. Generated by `python -m bslm.commands_bench`.

| | intent | intent and slots |
|---|---|---|
| **all commands** | **90.3%** | 85.4% |
| commands that also occur verbatim in the generated training set (19) | excluded below | |
| **clean subset, never seen in training (125)** | **88.8%** | |

The verbatim overlap is unavoidable for short generic commands ("louder",
"good morning", "kill the timer"); the clean subset is the honest number.
Overlapping commands: `kill the timer`, `what day is it today`, `what song is this`, `louder`, `too loud`, `ring the accountant`, `good morning`, `thanks a lot`, `perfect, thanks`, `ok bye`, `what can you do`, `say that again`, `never mind`, `forget it`, `what is left to decide`, `deploy`, `write me a poem about the sea`, `what is the meaning of life`, `μπλα μπλα μπλα`.

Bar: every domain with at least five commands at 80% intent accuracy or
better. Below is a fail, not a rounding error. Domains with fewer than five
commands are reported but not judged (18 of them); they need more
commands before the bar means anything.
